# tree-sitter-slang

Tree-sitter grammar for the S-Lang programming language.

This repository is used by the first-party Zed S-Lang extension. The grammar is intentionally independent from the S-Lang runtime and language server.

Before Zed submission, create a public Git repository from this directory, tag/release the intended grammar revision, and set that immutable commit in the Zed extension's `extension.toml`.
