S-Lang 1.0 — English LaTeX User Manual

File:
  S-Lang_1.0_User_Manual_EN.tex

Overleaf:
1. Create a blank project.
2. Upload S-Lang_1.0_User_Manual_EN.tex.
3. Open Menu -> Compiler.
4. Select XeLaTeX (recommended) or LuaLaTeX.
5. Recompile.

Local compilation:
  xelatex -interaction=nonstopmode -halt-on-error S-Lang_1.0_User_Manual_EN.tex
  xelatex -interaction=nonstopmode -halt-on-error S-Lang_1.0_User_Manual_EN.tex

The document is self-contained. It does not require external images, bibliography files, or custom style files.
The standard-library catalog is included in the source and lists all 277 public function entries from the S-Lang 1.0 source tree.
